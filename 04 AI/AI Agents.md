# Summary
Autonomous systems that use LLMs to select actions, write code, and execute external tools.

# Key Concepts
- **Core Elements**: ReAct framework, loop-based execution, execution environments.
- **Agent vs System**: An agent is an entity capable of executing tasks autonomously. A system is a composition of multiple specialized agents collaborating to achieve a common goal.
- **IBM Bob**: An AI SDLC (Software Development Lifecycle) partner. Bob is NOT a single agent, but a system that coordinates agents, AI models, tools, and enterprise services to help the user.
  - **Capabilities**: Code generation, command execution, documentation, testing, refactoring, code analysis.
  - **Operating Modes**: Code mode, Advanced mode, Plan mode, Ask mode.
  - **Tools**: Read, write, command, MCP, mode, question tools.
  - **MCP**: Interaction with external tools.
- **Development Stack**: LangChain, LlamaIndex, OpenAI API, Anthropic SDK.
