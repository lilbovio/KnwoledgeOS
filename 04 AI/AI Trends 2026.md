# Summary
AI trends for 2026 highlighting the rapid pace of algorithmic improvement, multimodal architectures, AI agents, and the MCP standard.

# Key Concepts
- **Pace of Change**: +400% annual algorithmic improvement reported by IBM Think 2026. 44% of tech enterprises have implemented AI.
- **Shadow AI**: Unauthorized use of AI within companies is predicted to be the main vector for data leaks in 2026.
- **Multimodal AI Architectures**:
  - *Late fusion*: One encoder per modality, joined at the end.
  - *Early fusion*: Everything mapped to the same embedding space from the start.
  - *Unified tokenization*: Image, audio, and video are tokenized into discrete sequences.
  - *Examples*: GPT-5.2, Gemini 3, Claude 4.5, Veo 3.1.
- **AI Agents vs Chatbots**:
  - *Chatbot*: Waits for a question and responds with text.
  - *AI Agent*: Given a goal rather than a question; it calls APIs, writes files, sends emails, navigates the web, and runs code. It has short and long-term memory, uses tools and a planner, and reflects on its plans.
- **MCP (Model Context Protocol)**:
  - An open standard to connect LLMs with external tools and data.
  - Adopted by OpenAI, Google DeepMind, Replit, Sourcegraph, Block, Cursor.
  - Architecture: MCP Client talks JSON RPC with an MCP Server.
