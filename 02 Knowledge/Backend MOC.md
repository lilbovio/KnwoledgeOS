# 🖥️ Backend Map of Content (MOC)
*Server execution environments, API orchestration, and database operations.*

- [[Node.js]]: Asynchronous execution runtime, V8 engine.
- [[APIs]]: HTTP APIs, request parsing, routing protocols.
- [[PostgreSQL]]: Relational database querying and optimization.
- [[Authentication]]: User identity verification (JWT, OAuth, Cookies).
- [[Authorization]]: Checking access permissions (RBAC, ABAC models).
- [[Caching]]: Speeding up server response times using memory tables (Redis).
