# Summary
A system's capacity to handle growing traffic volumes by allocating hardware resources.

# Key Concepts
- **Core Principles**: Horizontal scaling (adding nodes), vertical scaling (adding CPU/RAM), load balancing, sharding.
- **Tradeoffs**: Balance execution velocity against clean architecture complexity.

Applied during coding and system architecture mapping in projects like [[OnboardIQ]] and [[POS System]].
