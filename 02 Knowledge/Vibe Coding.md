# Summary
The transition from manually writing code to generating code and leading systems, alongside the risks of "Vibe Coding."

# Key Concepts
- **Vibe Coding**: Accepting AI output without reviewing it, which accumulates technical debt.
- **AI Mistakes**: AI lacks context (business constraints, team policies) and can generate code that doesn't scale.
- **The Bottom Line**: Using AI without judgment is not productivity, it's risky.

# Practical Applications
Four steps to work with AI in software engineering:
1. Design
2. Document
3. Reset
4. Review
