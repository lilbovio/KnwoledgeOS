# Summary
Overview of the Software Development Lifecycle (SDLC) focusing on product and technical specifications.

# Key Concepts
- **Product Specs**: Written by the PM. Defines the "what" and the "why". Includes executive summary, user stories, scope, and success criteria.
- **Tech Specs**: Defines the "how". Includes data models, UI components, migrations, and risk/concerns.
- **SME**: Subject Matter Expert.

# Practical Applications
- Development starts only after both tech and product specs are signed.
- Stages: Development complete -> Code complete -> Quality assurance -> GA Ready.
