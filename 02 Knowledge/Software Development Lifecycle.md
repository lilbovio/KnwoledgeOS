# Summary
Overview of the Software Development Lifecycle (SDLC) focusing on product and technical specifications, automated pipeline gates, and release milestones.

# Key Concepts
- **Product Specs**: Written by the PM. Defines the "what" and the "why". Includes executive summary, user stories, scope, and success criteria.
- **Tech Specs**: Defines the "how". Includes data models, UI components, migrations, and risk/concerns.
- **SME**: Subject Matter Expert.
- **Automated Pipeline Flow**:
  $$\text{Plan} \longrightarrow \text{Code} \longrightarrow \text{Build} \longrightarrow \mathbf{\text{Test (CI/CD Automations)}} \longrightarrow \text{Release} \longrightarrow \text{Deploy} \longrightarrow \text{Monitor}$$

# Practical Applications
- Development starts only after both tech and product specs are signed.
- Stages: Development complete $\to$ Code complete $\to$ Quality assurance ([[Testing]]) $\to$ Automated Release ([[CI_CD]]) $\to$ GA Ready.
