# 🔌 Knowledge Capture Protocol
*Transforming raw information inputs into structured Obsidian notes.*

## Input-to-Action Mapping
This protocol outlines how raw inputs are parsed and written.

### Example Case Study
- **Raw Input**: *"I learned Sliding Window and solved LeetCode 3 today."*
- **Execution Workflow**:
  1. Open [[02 Knowledge/Algorithms/Sliding Window|Sliding Window.md]].
  2. Append **LeetCode 3** to the solved list.
  3. Create [[02 Knowledge/Algorithms/LeetCode 3|LeetCode 3.md]] using the standard template:
     - Link to [[Sliding Window]].
     - Write the solution logic and code block.
  4. Open [[00 Dashboard/Algorithms Dashboard|Algorithms Dashboard]] and increment the solved count.
  5. Check [[00 Dashboard/Learning Dashboard|Learning Dashboard]] and update the daily status checklist.
