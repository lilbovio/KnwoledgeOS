# Summary
Modern personal portfolio built using Next.js, React, TailwindCSS, and deployed on Vercel.

# Key Concepts
- **SSR & ISR**: Dynamic pages statically rendered using Next.js ISR (Incremental Static Regeneration) to optimize performance.
- **MDX Blog**: Local markdown integration for article reading.
- **Analytics**: Vercel Web Analytics tracking visitor numbers.
