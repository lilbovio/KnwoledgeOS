# Summary
Functional and non-functional requirements for the OnboardIQ MVP.

# Key Concepts
- **Functional Requirements**:
  - Secure Magic Link login and role-based access control (RBAC).
  - Dynamic interactive onboarding checklists.
  - Interactive Org Chart navigation.
  - Automatic progress notification to HR.
- **Non-Functional Requirements**:
  - SOC-2 compliant data protection.
  - Sub-second UI state transition latency.
  - Responsive design supporting web and mobile views.
