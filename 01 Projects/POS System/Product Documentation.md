# Summary
Point of Sale system sold to a regional liquor store chain. Resolves transaction processing and real-time inventory management.

# Key Concepts
- **Local Cache Resiliency**: Allows transactions to compile even during internet drops.
- **Inventory Subsystem**: Automated triggers when stock levels fall below set minimums.
- **Multi-Terminal Sync**: Live PostgreSQL replication across different cashier terminals.
